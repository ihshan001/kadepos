# Room schemas — commit these

Room writes one JSON file per schema version into this directory
(`com.example.data.db.PosDatabase/1.json`, `2.json`, …) on every build.

**These files must be committed.** They are not build output in any meaningful
sense — they are the record of what the database looked like at each released
version, and Room uses them to verify that every migration in
`data/db/Migrations.kt` actually produces the schema it claims to.

Without them:

- Room cannot validate migrations at build time, so a wrong `ALTER TABLE` is
  only discovered when a real shop updates the app and it crashes on launch.
- `MigrationTestHelper` in `androidTest` has nothing to migrate *from*.

They are generated by the `room.schemaLocation` KSP argument in
`app/build.gradle.kts`, and will appear the first time the project is built
with a JDK and the Android SDK available.

## Rules

- Never edit a JSON file by hand.
- Never delete one for a version that has shipped.
- If a schema file changes without a version bump, someone altered a released
  schema in place — that is a bug, not a merge conflict to resolve away.
